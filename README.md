# Aurora Wallet — versions officielles

Ce dépôt contient uniquement les **fichiers d'installation Android** (APK) d'Aurora Wallet,
le portefeuille Bitcoin Lightning simple, compagnon du projet AURORA.

- Téléchargez la dernière version dans **Releases**, à droite.
- Chaque version indique l'empreinte SHA-256 du fichier et celle du certificat de signature.
- L'application vérifie elle-même s'il existe une nouvelle version et propose de l'installer.

Android refuse toute mise à jour qui ne serait pas signée par la même clé que la version installée.

## Vous aviez Aurora Éclair (version 0.3.0 ou avant) ?

À partir de la version 0.4.0, l'application a un nouvel identifiant Android : c'est une nouvelle
application, elle ne remplace pas l'ancienne.

1. Dans l'ancienne application, vérifiez que vos **12 mots** sont bien notés.
2. Installez Aurora Wallet 0.4.0 (ou plus récente).
3. Choisissez « Restaurer un portefeuille » et tapez vos 12 mots.
4. Quand tout est là, désinstallez l'ancienne application.
